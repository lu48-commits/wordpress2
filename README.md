# AS Colour Inspired WordPress Theme

This repository contains a custom WordPress storefront theme named **AS Colour Inspired Commerce**. It is designed to evoke the clean, premium apparel shopping structure of AS Colour while using original layout code, original copy, and CSS-generated placeholder visuals instead of copied images.

## Install

1. Copy `wp-content/themes/ascolour-inspired` into your WordPress installation.
2. In the WordPress admin, go to **Appearance → Themes** and activate **AS Colour Inspired Commerce**.
3. Optional: install WooCommerce and create pages for `/shop/`, `/cart/`, and `/my-account/`.
4. Optional: set **Settings → Reading → Your homepage displays** to a static home page to use the theme's `front-page.php` layout.

## Customization

- Use **Appearance → Menus** to replace the fallback Men/Women/Kids/Headwear/Outlet/About navigation.
- Use **Appearance → Customize → Site Identity** to upload a logo.
- Add widgets to **Footer Newsletter** to replace the default newsletter form.
- Replace placeholder panels with featured images or WooCommerce product imagery when final assets are ready.
