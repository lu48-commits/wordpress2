# LeoLeo B2B WordPress Theme

Responsive WordPress theme for `leoleofactory.com`, focused on B2B apparel manufacturing, premium blanks, OEM, ODM, private label production, and RFQ lead generation. The visual direction references the clean wholesale apparel structure of AS Colour while using original LeoLeo Factory copy, layout decisions, and styling.

## Install

1. Upload `wp-content/themes/leoleo-b2b` to your WordPress installation.
2. In WordPress admin, go to Appearance -> Themes and activate **LeoLeo B2B**.
3. Set the site title to `LeoLeo Factory`.
4. Optional: create menus for Primary and Footer, or use the built-in anchor fallback menu.
5. Optional: replace the RFQ email flow with Contact Form 7, WPForms, Fluent Forms, HubSpot, or a CRM integration.

## Included

- Custom WordPress theme header and front page template.
- OEM/ODM capabilities, product categories, process, quality signals, and RFQ form.
- Responsive CSS for desktop and mobile.
- WooCommerce theme support for future product/catalog expansion.
